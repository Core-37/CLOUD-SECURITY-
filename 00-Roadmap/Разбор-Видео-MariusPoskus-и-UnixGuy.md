## 1. Уроки CISO Marius Poskus (`@mariusposkus0`)

**Кто это:** действующий руководитель службы безопасности (CISO) в финтехе, нанимающий руководитель и автор концепции *«Proof over Paper»* (Доказательства важнее бумажек).

### Главные тезисы из его видео по Cloud Security:
1. **Ловушка «коллекционера сертификатов» (The Proof Problem):**
   - Нанимающий менеджер каждый день видит десятки резюме с одинаковым набором базовых сертификатов и **абсолютно пустым GitHub**.
   - **Вывод:** нельзя тратить сотни долларов и месяцы на заучивание тестов, если ты ни разу не написал код инфраструктуры, не настроил аудит и не расследовал утечку на практике.
2. **Отказ от дорогих буткемпов и мифа о «нужном дипломе»:**
   - В Cloud Security Engineering смотрят на то, умеешь ли ты **автоматизировать защиту**. В реальных компаниях облако не настраивают руками мышкой — его разворачивают через **Infrastructure as Code (Terraform)**.
3. **Связка, которая даёт работу в 2026+:**
   - **Облако (AWS или Azure)** + **IAM Least Privilege** (строгие роли и политики) + **Terraform + DevSecOps-сканеры** (проверка шаблонов до деплоя) + **Cloud SIEM / XDR** (мониторинг через `GuardDuty`, `CloudTrail`, `Microsoft Sentinel`).
4. **Домашняя лаборатория = Опыт работы в портфолио:**
   - Если у тебя нет коммерческого стажа, твои **воспроизводимые проекты на GitHub** (с `README`, архитектурой, примером атаки и исправления) становятся главным доказательством квалификации.

## 2. Уроки UnixGuy (`https://www.youtube.com/watch?v=r86YCwX_iU4`)

**Название видео:** *«FASTEST Way to Learn Cloud Security and ACTUALLY Get a Job»* (Самый быстрый способ выучить Cloud Security и реально получить работу).

### Ключевая стратегия без самообмана:
1. **Честная реальность рынка:**
   - *Cloud Security Engineer* — это редко самая первая позиция в жизни без знания основ ИТ. Чтобы защищать облако, сначала нужно понимать, как оно работает.
2. **Не распыляйся на 3 облака сразу:**
   - На старте выбери **ОДНОГО** лидера рынка:
     - **Amazon AWS** (мировой лидер по облачным вычислениям, стартапам, инфраструктуре) **ИЛИ**
     - **Microsoft Azure** (доминирует в корпоративном секторе, банках, интеграции с Office 365 / Entra ID и SIEM Microsoft Sentinel).
   - *Google Cloud (GCP)* — отличный третий вариант (особенно в AI/Kubernetes и сильная экосистема безопасности Mandiant), но первым лучше учить AWS или Azure, где больше вакансий.
3. **Чёткая последовательность слоёв:**
   - **Слой 1 (IT-фундамент):** Сети (`TCP/IP`, `DNS`, `HTTP/HTTPS`, `CIDR` подсети) + операционная система **Linux** и базовые концепции безопасности.
   - **Слой 2 (Само облако):** Как создаются серверы (`EC2/VM`), хранилища (`S3/Blob`), базы, сети (`VPC/VNet`) и как работает **IAM**.
   - **Слой 3 (Безопасность облака):** Настройка ограничений, шифрование (`KMS`), сканирование уязвимостей и сбор логов (`CloudTrail` / `Azure Monitor` / `GuardDuty`).
4. **Упаковка под HR и ATS-фильтры:**
   - Откажись от пассивного «просмотра видео» (*Tutorial Hell*). Каждую изученную тему переводи в проект и прописывай в резюме точными техническими терминами индустрии.

## 3. Интеграция GitHub `90DaysOfCyberSecurity` и `Awesome-Hacking`

### Как план `farhanashrafdev/90DaysOfCyberSecurity` ложится в наш курс:
В оригинальном 90-дневном плане дни распределены так, а мы адаптируем их строго под **Cloud Security**:

| Дни в `90Days` | Оригинальная тема | Как мы усиливаем это под **Cloud Security** в нашем курсе |
| :---: | :--- | :--- |
| **Дни 1–7** | Network+ | Фокус на **CIDR-подсети (`/16`, `/24`, `/32`)**, порты облака (`22`, `443`, `5432`, `6379`, `6443`), DNS и TLS + как они работают внутри **VPC** |
| **Дни 8–14** | Security+ | **Shared Responsibility Model**, триада CIA в облаке, аутентификация (MFA, OIDC, STS-токены), криптография **KMS** |
| **Дни 15–28** | Linux | **SSH-ключи (`chmod 400`)**, права доступа, `systemd`, `ss -tulnp`, анализ логов и облачные задачи на **SadServers** |
| **Дни 29–42** | Python | Парсинг JSON-политик, работа с API и библиотекой **`boto3`**, написание собственных аудиторов IAM/S3 и сканера Terraform |
| **Дни 43–56** | Traffic Analysis | Анализ трафика в Wireshark/tcpdump + **VPC Flow Logs** (понимание, какой трафик разрешила Security Group, а какой заблокировала NACL) |
| **Дни 57–63** | Git | Защита репозиториев от утечки секретов: `.gitignore`, pre-commit хуки и сканирование истории через **Gitleaks** |
| **Дни 64–70** | SIEM (ELK) | Облачные логи и SIEM: **AWS CloudTrail**, **GuardDuty**, **Microsoft Sentinel (KQL)** и автоматическое реагирование (SOAR) |
| **Дни 71–77** | **Cloud (AWS/Azure)** | Расширено в нашем курсе до **4 глубоких фаз** (IAM, VPC, S3, KMS, SSRF/IMDSv2, IAM PrivEsc, Docker/K8s, Terraform + Checkov/Trivy/Prowler) |
| **Дни 78–95** | Хакинг & Резюме | Полигоны **`flAWS.cloud`**, **`flAWS2`**, **`PwnedLabs`**, **`Kubernetes Goat`** + 5 проектов портфолио + бесплатные бейджи и резюме |

В `Awesome-Hacking` собраны лучшие open-source инструменты и полигоны. Для облачной безопасности мы отобрали **главные рабочие инструменты (никакой свалки из 500 утилит)**:

- **Пентест-инструменты для учебных облачных полигонов:** `Pacu`, `CloudFox`, `aws-cli`, `nmap`, `ffuf`, `nuclei`.
