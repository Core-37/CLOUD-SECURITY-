## 1. 🎓 Университеты и Академические Курсы (100% Бесплатно через Audit / OpenCourseWare)

> 💡 **Лайфхак для Coursera & edX:** Не покупай подписку при входе. Нажми *Enroll for Free* и найди внизу мелкую ссылку **«Audit the course»** (на Coursera) или **«Free Audit Track»** (на edX) — ты получишь доступ ко всем видеолекциям бесплатно!

1. **MIT 6.858 — Computer Systems Security (MIT OpenCourseWare):**
   - 🔗 https://ocw.mit.edu/ (поиск `6.858`) и https://css.csail.mit.edu/6.858/
   - *Зачем:* фундаментальные лекции MIT о том, как работают изоляция, контейнеры, сети, модель угроз, веб-безопасность и разделение привилегий.
2. **Stanford CS155 — Computer and Network Security:**
   - 🔗 https://cs155.stanford.edu/
   - *Зачем:* легендарные конспекты и лекции Стэнфорда по сетевой безопасности, криптографии, защите браузера и серверной безопасности.
3. **University of Colorado — Cloud Computing Security (Coursera, Free Audit):**
   - 🔗 https://www.coursera.org/ (поиск *Cloud Computing Security University of Colorado*)
   - *Зачем:* университетский курс по основам облачной архитектуры AWS, защите виртуальных серверов и управлению доступом IAM.
4. **Stanford Online / YouTube Security Seminars:**
   - 🔗 https://www.youtube.com/@stanfordonline
   - *Зачем:* бесплатные лекции практиков из Кремниевой долины по облачной архитектуре, Zero Trust и контейнерам.
5. **Harvard CS50P — Introduction to Programming with Python (Бесплатно):**
   - 🔗 https://cs50.harvard.edu/python/
   - *Зачем:* лучший в мире старт по Python с нуля (необходим для автоматизации облака и `boto3`).
